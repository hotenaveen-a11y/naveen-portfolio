# HR Workforce & Employee Analytics

## Project Overview
This project analyzes employee workforce data to identify trends and patterns across departments, pay zones, work-life balance, and employee training programs.

The original dataset contains 2,845 employee records and 28 columns. This portfolio version uses aggregate summaries to protect employee privacy.

## Project Objectives
- Analyze employee distribution across departments.
- Examine average employee age by department.
- Understand workforce distribution across pay zones.
- Analyze work-life balance scores.
- Evaluate employee participation in training programs.
- Summarize department-wise pay-zone distribution.
