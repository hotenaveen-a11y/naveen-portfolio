# US Gasoline Price Trends & Analysis

## Project Overview

This project explores gasoline price data using Microsoft Excel to understand historical price movements and identify trends over time.

The dataset focuses on Washington, DC gasoline prices and provides an opportunity to examine regional fuel-price patterns.

## Project Objectives

- Analyze historical gasoline price movements.
- Identify changes and trends over time.
- Examine fluctuations in gasoline prices.
- Present findings through Excel charts and summaries.
- Develop insights from historical fuel-price data.

## Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Excel Charts

## Dataset

The project uses a publicly available gasoline price dataset.

The analysis is based on the data included in the original Excel workbook.

## Project Deliverable

The Excel workbook contains the source data and analysis.

## Disclaimer

This is an independent portfolio project using publicly available sample data. It is not based on confidential company information.
