# Electric Vehicle Population Analysis

## Project Overview
This project analyzes Electric Vehicle (EV) registration data to understand EV adoption trends, popular manufacturers and models, vehicle types, and county-level distribution.

## Tools Used
- Microsoft Excel
- Excel Pivot Tables
- Excel Charts
- Data Analysis

## Dataset
The dataset contains electric vehicle registration records from Washington State.

- Total Records: 177,866
- Model Years: 1997–2024
- Data Focus: Battery Electric Vehicles (BEV) and Plug-in Hybrid Electric Vehicles (PHEV)

## Key Analysis Areas
1. Number of EVs per County
2. Popular Makes and Models
3. EV Growth Over Model Years
4. Types of Electric Vehicles
5. Original Dataset Review

## Key Findings
- Battery Electric Vehicles (BEVs): 139,210
- Plug-in Hybrid Electric Vehicles (PHEVs): 38,656
- Tesla was the most represented manufacturer, with 79,659 vehicles.
- King County had the highest EV registrations, with 92,740 vehicles.
- Model year 2023 had the highest representation, with 57,587 vehicles.

## Project Objective
To explore electric vehicle adoption patterns, identify popular manufacturers, and understand geographic and model-year trends using Microsoft Excel.
